# C-003 — User quota & tier management UI

status: done
deps: C-002
implements: FR4

## Scope

- Xây dựng giao diện trang quản lý người dùng tại `/admin/users`.
- Cho phép tìm kiếm người dùng theo Email. Hiển thị thông tin: Email, Tier, Số lượt dùng đã dùng/tổng quota.
- Cho phép Admin thay đổi Tier (free/premium/admin) và nâng hạn mức `contractAnalysisLimit` thông qua API POST `/admin/users/{user_id}/quota`.
- Ghi log sự kiện đổi quota của user vào `AdminAuditLog` DB.
