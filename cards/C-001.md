status: done
deps: none

## Scope

Thiết lập khung giao diện Admin và cơ chế bảo vệ Route:
- Giao diện khung layout `/admin/layout.tsx` và trang Dashboard chính `/admin/page.tsx`.
- Sidebar điều hướng qua các tab: Thống kê, Quản lý User, Quản lý Checklist, Quản lý RAG, Playground.
- Middleware hoặc check trực tiếp trong layout kiểm tra session NextAuth: Chỉ email nằm trong danh sách `ADMIN_EMAILS` (cấu hình qua `.env`) hoặc user có `tier: "admin"` trong DB được phép truy cập. Mọi truy cập trái phép bị redirect về `/` kèm flash message báo lỗi.
