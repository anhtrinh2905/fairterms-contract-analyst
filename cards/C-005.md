# C-005 — RAG Document Management UI & Ingestion

status: done
deps: C-002
implements: FR2

## Scope

- Thiết lập giao diện trang quản lý RAG tại `/admin/rag`.
- Giao diện gồm:
  - Bảng danh sách văn bản pháp luật hiện có trong vector store (lấy dữ liệu từ endpoint `GET /admin/rag/documents` gọi `list_documents()`).
  - Khu vực tải lên file Markdown (`.md`) để nạp văn bản mới vào ChromaDB.
- Backend API `POST /admin/rag/ingest` tiếp nhận file tải lên, lưu vào file tạm và thực hiện chạy hàm `ingest_legal_markdown(filepath)` từ pipeline RAG có sẵn.
- Trả về số lượng parents/children chunks đã nạp thành công và cập nhật lên UI.
- Ghi log sự kiện nạp tài liệu vào `AdminAuditLog` DB.
