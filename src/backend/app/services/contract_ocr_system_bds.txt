- Keep tables as Markdown tables when possible; payment schedules and land description tables must preserve every row.
- For scanned GCN / certificate appendices: transcribe all fields (owner, parcel numbers, area, land use, issue date) even if layout is irregular.
- Drop noise that is not part of the contract (scan-app watermarks, repeated page numbers, repeated headers/footers) unless it carries legal meaning.
